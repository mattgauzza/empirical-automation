# Ideas taste

What the owner accepts and rejects, and why. The ideas agent keeps this file (`agents/ideas.md`);
every agent that proposes or judges content reads it first. Sample content, made up.

## So (the rules these add up to)
1. Done in under 15 minutes, start to finish. No waiting overnight.
2. Five ingredients or fewer, all from an ordinary supermarket.
3. A tip must be true and say what to do, not just what to avoid.
